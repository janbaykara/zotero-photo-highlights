---
title: What is a syllabus?
description: How Zotero Syllabus turns a collection into a structured reading list.
---

In this plugin, a **syllabus** is an ordinary Zotero **collection** plus structured plugin data (stored in a note titled **Syllabus document -** your collection name) that groups items into **classes** (or weeks / sessions), with priorities, instructions, done state, and optional reading dates.

You still use Zotero as usual: items live in your library; the collection membership does not change when you assign a class. Syllabus view is another way to look at and edit that structure.

## Syllabus vs Gallery

Same collection, two toolbar views:

| | **Syllabus** | **Gallery** |
| --- | --- | --- |
| Best for | A course (weeks / sessions) | A personal reading list |
| Needs Turn into Syllabus? | Yes | No |
| Organizes by | Classes, priorities, instructions | Covers, your reading order, optional description |

You can use **both** on one collection (switch in the toolbar), or only Gallery if you never need classes. See [Gallery](/zotero-syllabus/how-to/gallery/) and [Personal reading order](/zotero-syllabus/concepts/personal-reading-order/).

## Surfaces that use syllabus data

- **Syllabus** tab — edit classes and assignments
- **Reading Schedule** — classes that have reading dates
- **Gallery** — can sort/group by class on syllabus collections (Home collection shelves)
- **Table** column **Syllabus Class / Assignment**
- **Print / publish** — exports the structured list

## What a syllabus is not

- Not a separate Zotero library or group type
- Not the same as [Gallery](/zotero-syllabus/how-to/gallery/) (reading-list browse without classes)
- Not the same as [pinning](/zotero-syllabus/how-to/pinning/) or [Home](/zotero-syllabus/how-to/home/) shelves
- Not automatically shared with collaborators unless you share the library / group or [publish](/zotero-syllabus/how-to/print-export-publish/)

## Creating one

Select a collection → **Turn into Syllabus**. You can reverse course by removing syllabus structure from Settings if you no longer need it (items stay in the collection).
